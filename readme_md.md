Repositório dedicado ao estudo e à consolidação dos conceitos fundamentais de algoritmos em Python, focando na estrutura clássica de solução de problemas: **Entrada de Dados**, **Processamento** e **Saída de Resultados**.

---

## 📌 Sobre o Projeto

Este projeto reúne scripts práticos e exercícios para fixação de sintaxe básica, manipulação de variáveis, conversão de tipos de dados (Casting), operações aritméticas e interação com o usuário através do terminal.

### 📚 Conceitos Praticados:
* **Variáveis e Tipos de Dados:** Declaração de números inteiros (`int`), decimais (`float`), textos (`str`) e booleanos (`bool`).
* **Entrada de Dados:** Leitura de inputs do usuário via terminal (`input()`).
* **Conversão de Tipos (Type Casting):** Transformação de entradas de texto em valores numéricos (`int()`, `float()`).
* **Processamento Aritmético:** Operações de adição, multiplicação e subtração.
* **Saída Formatada:** Exibição de informações com `f-strings` e função `print()`.

## 📂 Estrutura do Repositório

| Arquivo | Descrição |
| :--- | :--- |
| `Entrada-processamento-saida.py` | Exemplo introdutório demonstrando criação de variáveis, atualização de saldo e impressão de valores no terminal. |

## 🛠️ Como Executar os Scripts

### Pré-requisitos

Para executar os scripts, você precisará ter o **Python 3.x** instalado em sua máquina.

* [Download do Python](https://www.python.org/downloads/)

### Passo a Passo

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. **Acesse o diretório do projeto:**
   ```bash
   cd seu-repositorio
   ```

3. **Execute qualquer um dos scripts:**
   ```bash
   python Exercicio01.py
   ```
   *(Ou `python3 Exercicio01.py` dependendo do seu sistema operacional)*
